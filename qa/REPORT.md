## 화면 비교

Figma PNG와 Chromium 렌더링을 프레임별 같은 규격으로 비교했습니다. 안티앨리어싱, 투명 오버레이, 그림자와 블러, 숫자 서체에 차이가 남아 있습니다. 브라우저와 기기별 합성 방식으로 인해 픽셀 일치율 100%는 확인되지 않았습니다.

| 차이 면적이 큰 화면 | 채널 절댓값의 평균 (0~255) | 한 채널이라도 24를 초과한 픽셀 |
| --- | ---: | ---: |
| `cid-sunrise-alarm` | 10.71 | 10.64% |
| `cid-approach-alert` | 8.45 | 10.05% |
| `mobile-destination-comparison` | 7.20 | 7.80% |
| `cid-onboarding-pair` | 8.16 | 7.25% |
| `mobile-route-confirmation` | 5.86 | 6.90% |

전체 값은 `visual-results.csv`에서 확인할 수 있습니다. 위 지표는 색 채널 차이로 계산하며 화면·텍스트 배치만을 뜻하지 않습니다.

## 동작 검증

모바일 온보딩, 필수·선택 약관, 비상연락처 순서와 마스킹, 추천 카드 롤링·북마크와 검색 조건, 차량 설정과 알람, 배터리·V2L 경고, 접근 경보, CID 전환, 실시간 값 갱신, 컴포넌트 검색을 확인했습니다. 320px 모바일과 1024px 차량 화면의 스케일도 확인했습니다.

실제 기기 Android WebView의 센서·카메라 승인 흐름, 차량 SDK, 운영 인증, 문자·긴급 호출, 배포 서명은 연동 환경에서 확인해야 합니다. jsQR로 테스트 이미지를 판독하고, 브라우저에서 스캔 성공 콜백 이후 서버 응답과 화면 전환을 확인했습니다.
